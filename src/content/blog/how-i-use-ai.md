Everywhere. I try to use AI everywhere I can. The reason — I was afraid of this new technology for a while, but then I bought a GPT plan and everything changed. I’m trying to be on the edge of this tech. Cant imagine now, living without AI, so many fields it helps me with.

Framework is simple. I just ask: Can AI do this? Will it make the process more enjoyable for me? If yes, then I search for the appropriate tool and embed it into any workflow. Key disclaimer — don’t replace things u love to do. Value them and keep around. Life is full of suffering, leave things that make u happy close, don’t delegate.

**Writing**

I write via Lex.page. I call it Google Docs on steroids because it’s doc editing tool with all possible AI models embedded inside. I can create reusable prompt, chat with my writing, fix my grammar, check for clichés, clickbait, etc. I rarely ask it to rewrite my text, but to edit and fix meaning-breaking errors. I absolutely love to write, but hate editing. For my ADHD, it’s annoying and boring. I delegate here.

**Research**

With GPT I realized how inefficient Google Search is. Its a tool which scans for matches in words, without understanding any meaning and context. That’s why it’s perfect for SEO and Search ads — targeting what you type. LLMs on the other hand can understand bit more, so I use GPT and Perplexity for any kind of research. According to latest public report in 60% of cases models are wrong, so I recheck facts and especially numbers, but otherwise I trust it. In 40% cases its right, isnt it?

**Learning everything**

History, Math, Physics, Spanish, English grammar. GPT is my ultimate teacher in every possible field. I have no specific framework, I just chat and push my curiosity to the edges of each field. My favorite thing is seeking for gaps in my understanding. Every week I ask some weird stuff about space, and how Newton’s time theory differentiate with what Einstein came up later.

**Coding**

I code with [Bolt.new](http://Bolt.new) and Lovable, which models are quite stupid (Cursor isnt much smarter). So I export the project code to GPT and chat about it, trying to fix bugs, understand the logic. I significantly increased my understanding of coding projects and how to fix various technical issues with documentation, code base, etc.

**Any routine I hate**

Listening to long voice messages, editing podcasts, making designs for presentations, analyzing massive amounts of raw data, building math formulas, etc.

**Discussing my views on books, articles, movies, ideas**

I never ask for summary of any content, which I potentially could enjoy consuming. Only stuff I don’t want to. But generally when I watched something, listened to, or read I jump into discussing ideas from content and accelerate it into different sides. That’s how I come up with new ideas for anything. As there aren’t any new ideas, the only thing u could do, is to consume others’ ideas and reproduce something new out of it.
